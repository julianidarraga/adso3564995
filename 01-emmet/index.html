01-emmet

Plugin for faster HTML and CSS coding

01-Child >

Creates Child elemts (nesting).

Example:

ul>li>a ↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling +

Creates sibling elements.

Example:

header*section*footer ↔️

Result:

<header></header> <section></section> <footer></footer>

03-Multiplication *

Respects elemnts multiple times.

Example:

    li*3 ↔️

Result

><ul> <li></li> <li></li> <li></li> </ul>

04-Class .

Create a class atribute.

Example

div.Important ↔️

danger ↔️

Result

<div>class="Important"</div> <div class "danger"></div>

05-Classes ...

Creates multiple class attributes

Example:

div.clase1.clase2.clasen ↔️

Result:

<div class=red green blue"> </div>

06-Identification #

Creates an ID atrribute.

Example

menu#cod123 ↔️

Result:

<menu id= "cod123"></menu> </div>

07-Text {}

Insert text content.

Examples:

p{lorem ipsum dolor} ↔️

a{click here} ↔️

Result:

<p>lorem ipsum dolor</p> <a href="">click here</a>

08-Custom attributes []

Creates custom attributes.

Example:

input[type=number] ↔️

Result:

<input type="number">

09-Item Numbering $

Adds consecutive numbers.

Examples:

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Reverse Numbering @-

Inverts numbering order.

Example:

ul>li.num$@-*3 ↔️

Result:

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

11-Base Numbering @n

Defines a base number for sequences.

Example:

ul>li.num$@3*4 ↔️

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up ^

Moves up one level.

Example:

section>article>div^p ↔️

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping ()

Groups elements together.

Example:

(header>nav)(section>article) ↔️

Result:

<header> <nav></nav> </header> <section> <article></article>

14-Lorem lorem

Generates placeholder text.

Examples:

lorem ↔️

lorem20 ↔️

lorem*5 ↔️

Result:

Lorem ipsum dolor

15-HTML Documents html:

Creates various HTML document types.

Example:

html:xs —— Documento xhtml 1.0 Strict ↔️

html:xt —— Documento xhtml 1.0 Transitional ↔️

html:4s —— Documento html 4.01 Strict ↔️

html:4t —— Documento html 4.01 Transitional ↔️

html:5 —— Documento html 5 ↔️

Result:

<html:xs></html:xs> <html:xt></html:xt> <html:4s></html:4s> <html:4t></html:4t>

16-Meta Tags meta:

Generates meta tags.

Example:

meta:vp ↔️

Result:

<meta name="viewport" content="width=device-width, initial-scale=1.0">
