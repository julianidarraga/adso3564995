01-Emmet

Plugin for faster HTML and CSS coding.

01-Child >

Creates child elements (nesting).

Example:

ul>li>a ↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling +

Creates sibling elements.

Example:

header+section+footer ↔️

Result:

<header></header> <section></section> <footer></footer>

03-Multiplication *

Repeats elements multiple times.

Example:

ul>li*3 ↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class .

Creates a class attribute.

Examples:

div.important ↔️

.danger ↔️

Results:

<div class="important"></div> <div class="danger"></div>

05-Classes ...

Creates multiple class attributes.

Example:

div.red.green.blue ↔️

Result:

<div class="red green blue"></div>

06-Identification #

Creates an ID attribute.

Example:

menu#cod123 ↔️

Result:

<menu id="cod123"></menu>

07-Text {}

Inserts text content.

Examples:

p{lorem ipsum dolor} ↔️

a{Click Here} ↔️

Results:

<p>lorem ipsum dolor</p> <a href="">Click Here</a>

08-Custom Attributes []

Creates custom attributes.

Example:

input[type=number] ↔️

Result:

<input type="number">

09-Item Numbering $

Adds consecutive numbers.

Example:

ul>li.option$$*3 ↔️

Result:

<ul> <li class="option01"></li> <li class="option02"></li> <li class="option03"></li> </ul>

10-Reverse Numbering @-

Inverts numbering order.

Example:

ul>li.option$$@-*3 ↔️

Result:

<ul> <li class="option03"></li> <li class="option02"></li> <li class="option01"></li> </ul>

11-Base Numbering @n

Defines a base number for sequences.

Example:

ul>li.option$$@6*3 ↔️

Result:

<ul> <li class="option06"></li> <li class="option07"></li> <li class="option08"></li> </ul>

12-Climb Up ^

Moves up one level.

Example:

section>article>div^p ↔️

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping ()

Groups elements together.

Example:

(header>nav)+(section>article) ↔️

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-lorem lorem

Generates placeholder text.

Example:

lorem ↔️

lorem5 ↔️

lorem*3 ↔️

Result:

Lorem ipsum dolor sit amet.

15-HTML Documents !

Creates various HTML document types.

Example:

html:5 ↔️

! ↔️

Result:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Document</title> </head> </html>

16-Meta Tags meta

Generates meta tags.

Example:

meta:utf ↔️

meta:vp ↔️

Result:

<meta http-equiv="Content-Type"> <meta name="viewport">
